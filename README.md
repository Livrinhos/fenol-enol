# Yakuza Archive: Genesis

Construa YAKUZA ARCHIVE em fases. AGORA faça SOMENTE FASE 1 + FASE 2: identidade visual, abertura cinematográfica e seleção/gerenciamento de perfis. NÃO crie Home, catálogo, episódios, trailer, arquivo ou modo cinema ainda.

Identidade premium JAPAN + CRIME DOCUMENTARY: #030303 #090909 #121212 #F2F1EC #888888 #720000 #B51616 #B89B62. Preto dominante, vermelho como destaque e dourado mínimo. Editorial, sofisticado, cinematográfico, muito espaço negativo. Referências japonesas discretas: textura de papel, ondas, ukiyo-e, selos/carimbos, arquitetura/Tóquio. NÃO anime, NÃO cyberpunk, NÃO excesso de samurai/katana.

ABERTURA: fullscreen, minimalista, fundo preto. Sequência animada suavemente com fade/blur/scale e movimento vertical mínimo: JAPAN / ARCHIVE / 2026; depois YAKUZA; depois A HISTÓRIA POR TRÁS DO CRIME ORGANIZADO JAPONÊS; depois DOCUMENTÁRIO INTERATIVO. Transição elegante para perfis.

PERFIS: 'QUEM ESTÁ ASSISTINDO?' com Henrique, Participante 2, Participante 3, Participante 4. Avatar/foto, hover, seleção e foco. GERENCIAR PERFIS permite alterar nome e imagem, preview, salvar/cancelar; usuário pode escolher imagem. Persistir em localStorage nome, imagem e perfil selecionado. Sem backend.

Responsividade real mobile/desktop, acessibilidade (keyboard, focus-visible, aria, alt, reduced motion, contraste), sem usar overflow:hidden para esconder problemas. Validar visualmente e corrigir esta etapa antes de avançar para qualquer outra fase.
